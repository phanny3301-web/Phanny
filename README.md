# ClassTrack — ប្រព័ន្ធគ្រប់គ្រងវត្តមាន

ប្រព័ន្ធនេះប្រើ Node.js built-ins ដូច្នេះមិនចាំបាច់ដំឡើង package បន្ថែមទេ។ ត្រូវមាន Node.js 18 ឬថ្មីជាងនេះ។

## ចាប់ផ្តើមលើ Windows

1. ដំឡើង Node.js បើកុំព្យូទ័រមិនទាន់មាន។
2. ចុចពីរដងលើ `start.bat` ឬបើក Terminal នៅក្នុងថតនេះ ហើយដំណើរការ `node server.js`។
3. បើក http://localhost:8000 ក្នុង browser។
4. ពេលចូលលើកដំបូង បង្កើតគណនីអ្នកគ្រប់គ្រង។ ប្រើពាក្យសម្ងាត់យ៉ាងតិច ១០ តួអក្សរ ហើយរក្សាវាឲ្យមានសុវត្ថិភាព។

ទិន្នន័យរក្សាទុកក្នុង `attendance-data.json` នៅលើកុំព្យូទ័រដែលដំណើរការ server។ គណនីគ្រូ និងអ្នកគ្រប់គ្រងដែលចូល server ដូចគ្នានឹងប្រើទិន្នន័យរួម។ ចេញពី server ដោយចុច Ctrl+C នៅក្នុងបង្អួចដែលកំពុងដំណើរការ។

## ប្រើលើឧបករណ៍ច្រើនក្នុងសាលា

ដំណើរការ server សម្រាប់ចែករំលែកលើបណ្ដាញសាលា ដោយកំណត់ `HOST=0.0.0.0` មុន `node server.js` លើកុំព្យូទ័រម៉ាស៊ីនមេ ហើយឲ្យឧបករណ៍ផ្សេងទៀតបើក `http://IP-របស់-ម៉ាស៊ីនមេ:8000`។ ត្រូវអនុញ្ញាត port 8000 ក្នុង firewall តាមតម្រូវការ និងប្រើតែក្នុងបណ្ដាញដែលទុកចិត្ត។ Server ដែលបានផ្ដល់នេះមិនមាន HTTPS ទេ ដូច្នេះកុំបញ្ជូនពាក្យសម្ងាត់តាមអ៊ីនធឺណិតសាធារណៈ។ សម្រាប់ការប្រើតាមអ៊ីនធឺណិត ត្រូវដាក់នៅក្រោយ HTTPS reverse proxy ឬ hosting ដែលមាន TLS និងការថែទាំសុវត្ថិភាព។

## មុខងារ និងសិទ្ធិ

- គណនីគ្រូអាចចូលប្រើ និងកត់វត្តមាន; អ្នកគ្រប់គ្រងអាចបន្ថែមគណនី និងគ្រប់គ្រងសិស្ស/ថ្ងៃឈប់/backup។
- កត់វត្តមាន ថ្ងៃជ្រើសរើស ស្វែងរកសិស្ស និងស្ថិតិប្រចាំថ្ងៃ។ កាលបរិច្ឆេទដែលមិនទាន់កត់បង្ហាញថា «មិនទាន់កត់»។
- របាយការណ៍ប្រចាំខែ និង CSV; កំណត់ថ្ងៃឈប់សម្រាក។
- នាំចូលសិស្សតាម CSV។ ប្រើប៊ូតុង «គំរូ CSV» ដើម្បីទាញយកទម្រង់ត្រឹមត្រូវ៖ `id,name,className,email`។ លេខសម្គាល់ត្រូវតែមានតែមួយគត់។
- Backup ទាញយកជា JSON និងស្ដារពី JSON។ ស្ដារនឹងជំនួសសិស្ស/វត្តមាន/ថ្ងៃឈប់ទាំងអស់; គណនីអ្នកប្រើមិនប្ដូរទេ។ រក្សាទុក backup នៅកន្លែងមានសុវត្ថិភាព។

## ទីតាំងទិន្នន័យ

ឯកសារទិន្នន័យត្រូវបានបង្កើតដោយស្វ័យប្រវត្តិជាលើកដំបូង។ ដើម្បីរក្សាទុកទិន្នន័យ សូមកុំលុប `attendance-data.json` ហើយធ្វើ backup តាមផ្ទាំងការកំណត់ជាប្រចាំ។
